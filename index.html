Comment l'ajouter à mon agenda ?

iPhone / Mac : ouvre le fichier téléchargé, choisis le calendrier puis « Ajouter tout ».

Google Agenda : sur ordinateur, Paramètres → Importer et exporter → choisis le fichier et l'agenda.

Android – agenda Samsung :

  1. Télécharge le fichier avec le bouton ci-dessus.
  2. Ouvre-le depuis la notification de téléchargement ou l'appli « Mes fichiers ».
  3. Choisis « Agenda Samsung », puis l'agenda où ranger tes horaires, et valide.

Android – Google Agenda (l'appli ne sait pas importer un fichier, on passe par le site, directement sur le téléphone) :

  1. Télécharge le fichier avec le bouton ci-dessus.
  2. Ouvre dans Chrome la page d'import de Google Agenda. Si Google affiche sa version mobile : menu ⋮ → coche « Version pour ordinateur ».
  3. « Sélectionner un fichier sur votre ordinateur » → choisis le fichier dans « Téléchargements », choisis l'agenda, puis « Importer ».
  4. Ouvre l'appli Google Agenda : les jours apparaissent après quelques instants.

Astuce : la première fois, ajoute la page d'import en favori dans Chrome (☆). Pour les plannings suivants, il suffit de télécharger le fichier, d'ouvrir le favori et d'importer.

Si le planning change, refais l'export et réimporte-le : les jours déjà présents sont mis à jour, pas dupliqués.
